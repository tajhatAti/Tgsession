How do I get a session string?

Run this once on your own computer (with pip install telethon), enter your phone number and the login code, then copy the printed line:

python -c "
from telethon.sync import TelegramClient
from telethon.sessions import StringSession
c = TelegramClient(StringSession(), API_ID, API_HASH)
c.start()
print(c.session.save())   # <- copy this string
"

It grants full access to your Telegram account — never share it with anyone. If it stops working (revoked / used elsewhere), just paste a new one.
